Privacy

← Terug naar Knooppunten · English

Knooppunten is een gratis hobbyproject. Er zijn geen accounts, geen advertenties en geen tracking.

Wat er bewaard wordt

  • In je browser: je routes en je koppelcode (localStorage). Die blijven op je eigen apparaat. Als je de sitegegevens wist, ben je ze kwijt.
  • Op de server, alleen als je op "Verstuur naar horloge" drukt: de route die je verstuurt (naam, knooppuntnummers en hun posities, en eventueel de lijn van de route). De server bewaart de route alleen onder een hash van je koppelcode. De code zelf wordt niet opgeslagen.
  • Tegen misbruik: per dag wordt geteld hoe vaak er vanaf een IP-adres verstuurd wordt. Ook het IP-adres wordt alleen als hash bewaard, en de tellers worden elke dag gewist.

Hoe lang

Een route die 90 dagen niet is verstuurd of door het horloge is opgehaald, wordt automatisch verwijderd. Elke nieuwe verzending overschrijft de vorige route bij dezelfde code.

Wie er bij kan

Alleen wie je koppelcode kent, kan je route lezen of overschrijven. Deel je code dus niet. Het horloge haalt de route op via de Garmin Connect-app op je telefoon of via wifi.

Waar het draait

De website en de server draaien bij Cloudflare (Workers en D1). Daarbuiten worden er geen gegevens met anderen gedeeld.

Kaartgegevens

Knooppunten, verbindingen en plaatsnamen komen uit OpenStreetMap: © OpenStreetMap-bijdragers, beschikbaar onder de Open Database License.

Vragen

Wil je dat je route eerder verwijderd wordt, of heb je een andere vraag? Neem dan contact op via de pagina van de app in de Connect IQ Store.
